Poziom 2 · Kontrola

Git w pracy z agentami.

Agent zmienia pliki szybciej, niż człowiek je kontroluje.

Git zapisuje każdą dobrą wersję, pokazuje, co się zmieniło, i pozwala wrócić do poprzedniej. Komend nie trzeba pamiętać — zlecacie je agentowi zwykłym poleceniem albo skillem.

Format

Czas
Około 3 godzin z ćwiczeniem, zależnie od grupy
Dla kogo
Zespoły, w których ludzie i agenci pracują na tych samych plikach

Od pustego folderu do repozytorium i zmiany przeprowadzonej przez review
Programowanie
Nie jest potrzebne

Problem i rezultat

Koniec z plikami „final-v2-ostateczny”.

Po szkoleniu każda zmiana agenta jest zapisana, sprawdzona i możliwa do cofnięcia.

Po szkoleniu

Kontrolujesz historię pracy bez zapamiętywania komend.

  • wyjaśniasz, czym jest wersjonowanie i czym różni się Git od GitHuba;
  • zamieniasz folder projektu w repozytorium i zakładasz prywatne repozytorium;
  • zlecasz agentowi status, commit, push, restore i revert;
  • wiesz, co zapisać w repozytorium, a co wykluczyć w pliku .gitignore;
  • przeprowadzasz zmianę przez gałąź, pull request, review i merge;
  • planujesz małych agentów z właścicielami odpowiedzialnymi za ich pracę.

Program

Git jako pamięć projektu i punkt kontroli człowieka.

  1. 01

    Git i GitHub

    Wersjonowanie, commit i push. Co zapisujemy lokalnie, a co trafia do prywatnego repozytorium.

  2. 02

    Podstawowa pętla

    Status, commit, push oraz odrzucanie nieudanych zmian. Trzy sytuacje i trzy decyzje.

  3. 03

    Od folderu do repozytorium

    Instalacja i konfiguracja Gita, pierwszy commit, logowanie agenta i prywatne repozytorium.

  4. 04

    Praca w zespole

    Dostęp, pobranie projektu, osobna gałąź, pull request, review, poprawki, merge i pull.

  5. 05

    Git poza programowaniem

    Repozytorium jako pamięć agentów oraz system publikacji i akceptacji dla marketingu i treści.

  6. 06

    Zespół małych agentów

    Osobne odpowiedzialności dla strony, treści, social media, publikacji, kampanii i managera.

Dla kogo

Dla osób, które już pracują z agentem.

  • zespoły marketingu, treści i komunikacji,
  • specjaliści współdzielący pliki z innymi osobami i agentami,
  • osoby potrzebujące kontroli i akceptacji zmian,
  • uczestnicy Poziomu 1 albo osoby z praktycznym doświadczeniem pracy z agentem.

Ćwiczenie

Jedna zmiana od pomysłu do zatwierdzenia.

Wykonujecie zadania od pustego folderu do prywatnego repozytorium, a następnie przeprowadzacie zmianę przez pull request i review.

Po szkoleniu: prezentacja, ściąga poleceń i gotowe instrukcje do każdego zadania.

Wymagania

Laptop, GitHub i możliwość instalacji.

  • konto na GitHubie — można je założyć podczas szkolenia,
  • możliwość instalacji Gita na komputerze,
  • dostęp do wybranego agenta AI,
  • folder z przykładowym projektem lub materiałami.
