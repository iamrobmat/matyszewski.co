# Szkice

Ten katalog zawiera niepublikowane materiały robocze. `scripts/build-site.sh` nie kopiuje go do
artefaktów GitHub Pages ani Cloudflare Workers.

Szkic staje się wpisem publicznym dopiero po przeniesieniu źródła do `blog/posts/`, dodaniu
metadanych do `blog/posts/posts.json` i uruchomieniu generatora bloga.
