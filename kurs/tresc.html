Część 1

Przygotuj aplikację

Ustawiasz agenta raz, a potem korzystasz z tego przy każdym projekcie.

  1. 01

    Otwórz agenta

    Agent to osobny tryb albo osobna aplikacja.

    Claude Code

    W aplikacji Claude przełącz się na zakładkę Code.

    Codex

    Otwórz aplikację Codex i kliknij Nowy czat.

  2. 02

    Załóż projekt, czyli nowy folder

    Każdy projekt to osobny folder na dysku. Na ćwiczenie załóż folder, np. szkolenie-agent, i otwórz go w agencie.

    Claude Code

    Lista folderów → Open folder…

    Codex

    Wybierz projekt → Nowy projekt

    Nazwę folderu widać nad polem polecenia. Agent pracuje na plikach z tego folderu.

  3. 03

    Daj agentowi dostęp do Chrome

    Agent może czytać strony i klikać w Twojej przeglądarce. Przyda się w zadaniu i w ankiecie.

    Claude Code

    • Zainstaluj rozszerzenie Claude in Chrome.
    • Ustawienia → Claude in Chrome → Enable Claude in Chrome.
    • W Site permissions ustawiasz, na których stronach agent może działać.

    Codex

    • Ustawienia → Integracje → Korzystanie z komputera.
    • Google Chrome: zainstaluj rozszerzenie przeglądarki.
    • W tym samym miejscu dajesz zgodę na inne aplikacje, np. Excel.
  4. 04

    Ustaw uprawnienia

    Ty decydujesz, ile agent może zrobić bez pytania. Tryby idą od „pytaj o wszystko” do „działaj samodzielnie”. Na początek wybierz tryb, w którym agent pyta o zgodę.

    Claude Code

    Manual (zawsze pyta) → Accept edits → Auto → Bypass permissions

    Codex

    Poproś o zatwierdzenie → Zatwierdzaj za mnie → Pełny dostęp

    Tryb Plan oznacza: najpierw plan, potem zmiany. W obu aplikacjach włączysz go, wpisując /plan.

  5. 05

    Wyłącz trenowanie na Twoich danych

    Claude Code

    W aplikacji Claude: Settings → Privacy → wyłącz Help improve our AI models.

    Codex

    W przeglądarce: chatgpt.com → Ustawienia → Kontrola danych → wyłącz Pomóż ulepszać model dla wszystkich. Ustawienie dotyczy też Codeksu (to samo konto). Więcej: privacy.openai.com.

  6. 06

    Podłącz wtyczki opcjonalnie

    Wtyczki łączą agenta z aplikacjami, których używasz, np. Google Drive, Gmail czy Kalendarz Google.

    Claude Code

    Ustawienia → Connectors → Discover. Dodajesz jednym kliknięciem (+).

    Codex

    Ustawienia → Integracje → Wtyczki. Każdą włączasz przełącznikiem.

Część 2

Zadanie: pierwsza praca agenta

Skopiuj polecenie, wklej je agentowi w folderze projektu z kroku 2 i sprawdź wynik.

  1. 07

    Posteruj przeglądarką

    Sprawdź, czy agent ma dostęp do Chrome. Jeśli poprosi o zgodę na stronę, zatwierdź ją.

    Polecenie dla agenta

    Otwórz w Chrome stronę matyszewski.co/blog, wejdź w najnowszy wpis i streść go w trzech punktach.

  2. 08

    Pobierz plik

    Polecenie dla agenta

    Pobierz plik matyszewski.co/szkolenie.md i zapisz go w tym folderze.

    Sprawdź, czy plik szkolenie.md pojawił się w folderze projektu.

  3. 09

    Znajdź błędy ortograficzne

    Polecenie dla agenta

    Znajdź błędy ortograficzne w pliku szkolenie.md. Wypisz je w tabeli: błąd, poprawna forma, fragment zdania. Nie zmieniaj jeszcze pliku.

    Przejrzyj listę. Jeśli się zgadzasz, poproś agenta o poprawienie pliku.

  4. 10

    Zapisz notatki

    Polecenie dla agenta

    Utwórz plik notatki.md i zapisz w nim: [wpisz, co chcesz zapamiętać z dzisiejszego szkolenia].

    Otwórz notatki.md i sprawdź, co zapisał agent. Sprawdzanie pracy agenta to Twoja część pętli.

Gdy coś nie działa

  • Zapytaj, dlaczego nie działa, i popraw polecenie albo instrukcje.
  • Dziel duże zadania na etapy i zaczynaj od trybu planowania.
  • Otwórz nowy czat, gdy zmieniasz temat albo agent „gubi wątek”.
  • Zrestartuj aplikację albo zmień model, gdy coś przestaje działać bez powodu.

Część 3 · zadanie końcowe

Oceń szkolenie z pomocą agenta

Ostatnie ćwiczenie: agent wypełnia ankietę w przeglądarce, a Ty podajesz odpowiedzi i decydujesz o wysłaniu.

  1. 11

    Wypełnij ankietę agentem

    Polecenie dla agenta

    Otwórz w Chrome ankietę matyszewski.co/ankieta i pomóż mi ją wypełnić. Czytaj mi pytania po kolei i wpisuj tylko moje odpowiedzi. Zanim klikniesz „Prześlij”, pokaż mi wypełniony formularz i poczekaj na moją zgodę.

    Wysyłka na zewnątrz to decyzja człowieka, także w tej ankiecie. Jeśli agent poprosi o zgodę na stronę docs.google.com, zatwierdź ją.

    Agent nie daje rady? Otwórz ankietę samodzielnie.

Na koniec

Trzy rzeczy do zapamiętania

  1. Agent = model + cel + kontekst + narzędzia.
  2. Kontekst zapisuj w plikach, procesy w skillach.
  3. Eksperymentuj i sprawdzaj wyniki, zanim osiągniesz biegłość.
